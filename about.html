ABOUT THE PROJECT

Multiple layers. One secure workflow.

This demo combines ECC key agreement, authenticated encryption, hashing and image steganography.

ECDH / P-256

Shared key agreement

Sender and receiver derive the same key using their own private key and the other person's public key.

ChaCha20-Poly1305

Authenticated encryption

Encrypts message contents and detects ciphertext tampering.

SHA-256

Integrity digest

Creates a digest of the original message for verification.

Note: this runnable version uses lossless PNG LSB steganography, not a trained CNN model. Cloud storage is not configured.
